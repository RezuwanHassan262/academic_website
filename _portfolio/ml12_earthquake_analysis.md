Scraped earthquake data from a public seismic-records site covering Bangladesh, India, Bhutan and Myanmar (the BIBM sub-region) across more than a hundred years, then cleaned, curated and visualised the insights using Tableau.

### What it does
- **Selenium-driven scraping** of a dynamic, paginated seismic-records site
- **Dataset curation** — deduplication, magnitude/depth normalisation, geocoding cleanup
- **Tableau dashboards** — location-wise earthquake counts, magnitude distributions, and a regional map view for the BIBM sub-region

### Technologies
Python · Selenium · Web Scraping · Dataset Curation · Tableau
