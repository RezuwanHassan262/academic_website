AgriBuddy is an AI-powered, agent-based agricultural assistant system for Bangladeshi farmers using RAG and Vision Models. The system supports natural Bangla/Banglish text queries, image-based **rice disease detection** (CNN, 10 classes), and context-aware farming advice via a mobile-first PWA deployment.

### Key Features
- **Smart Query Handler** — routes user queries to appropriate agents
- **User Memory Agent** — maintains conversation context
- **Expert Advisory Agent** — RAG-powered domain knowledge
- **Vision Module** — CNN-based rice disease detection (10 classes)
- **Bangla/Banglish** natural language support
- Mobile-first Progressive Web App (PWA)

### Awards
**Runner-up — National AI Hackathon 2025** (Bangladesh Innovation Conclave, May 2025)
