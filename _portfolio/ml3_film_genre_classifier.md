Scraped movie and TV show data to build a multi-label genre classification system. Fine-tuned a **RoBERTa** transformer model on the curated dataset, converted the model to **ONNX** for faster inference, and deployed it via **Flask** on both Hugging Face Space and OnRender.

### Key Outcomes
- Custom scraped dataset of movie/TV metadata
- RoBERTa fine-tuned for multi-label classification
- ONNX export for optimised inference speed
- Live web application deployed on Render

### Technologies
Python · Text Classification · RoBERTa · Hugging Face · ONNX · Flask
