Scraped a dataset of parrot species images, then fine-tuned a **fast.ai** image classifier achieving **93% accuracy** across 60 species. Deployed the model on Hugging Face Spaces and integrated the inference API into a custom-built website hosted on Netlify.

### Key Outcomes
- **93% accuracy** across 60 parrot species
- Custom web-scraped image dataset (released publicly)
- Live demo website integrated with Hugging Face inference API

### Technologies
Python · Image Classification · Data Scraping · Fast.AI · Hugging Face
