A Bangla satirical chatbot inspired by *Unmad* magazine's comedic, sarcastic writing style. Retrieves relevant Bangla text snippets from a curated knowledge base via **Retrieval-Augmented Generation (RAG)** and answers queries with humorous, exaggerated, witty satire — preserving the cultural flavour of one of Bangladesh's most beloved humour publications.

### Technologies
OpenAI · Vector Database · Retrieval-Augmented Generation (RAG) · Hugging Face · LLM · Prompt Engineering
