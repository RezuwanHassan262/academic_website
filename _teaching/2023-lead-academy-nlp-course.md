Lead Academy approached me to design and deliver an NLP course by developing the pre-recorded content for it, and I accepted the offer. I worked as an instructor there on a contractual basis.

The course — **["Natural Language Processing (NLP) for Beginners using Python"](https://lead.academy/course/natural-language-processing-nlp-for-beginners-online-course)** — covers everything one might need to get started with NLP, from the very basics through to training deep learning models and using existing large language models.

### Coverage
- Text preprocessing, tokenisation, and classical NLP pipelines
- Vector representations and statistical language modelling
- Deep learning approaches to NLP tasks
- Working with pre-trained large language models
- Hands-on Python demonstrations for every concept, plus walkthroughs of the surrounding tooling and platforms

Rather than staying theoretical, each topic is demonstrated practically in Python alongside the relevant tools and platforms.
